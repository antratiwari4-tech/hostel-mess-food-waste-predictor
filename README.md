# Hostel Mess Food Waste Predictor

## Overview
This project aims to analyze hostel meal demand and explore how data science can help reduce food waste.

## Problem Statement
Hostel kitchens may prepare more or less food than students need. Better demand estimates could help improve meal planning.

## Project Objectives
- Analyze meal attendance and food preparation data.
- Identify patterns in demand across days and meal types.
- Build a machine learning model to predict meal demand.
- Estimate potential food waste using available data.
- Present findings through charts and visualizations.

## Planned Tools
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- GitHub

## Project Status
In progress. Dataset preparation, analysis, model development, and evaluation are planned.

## Data Note
Results and model performance will be reported after testing. Any simulated data will be clearly identified as simulated.
